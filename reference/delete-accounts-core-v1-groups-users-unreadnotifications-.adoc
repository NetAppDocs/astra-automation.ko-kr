= 그룹에 속한 사용자의 읽지 않은 알림을 삭제합니다
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
그룹 내 사용자의 읽지 않은 알림을 삭제합니다. 이 기능을 사용하여 그룹 활동에서 알림 상태를 관리하고 유지할 수 있습니다.



[[http-method-and-endpoint]]
== HTTP 메서드 및 끝점입니다

[.api-doc-operation .api-doc-operation-delete]#삭제# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/groups/{group_id}/users/{user_id}/unreadNotifications/{unreadNotification_id}`#



[[usage-notes]]
== 사용 참고 사항

지정된 읽지 않은 알림 API 리소스를 제거합니다.



[[parameters]]
== 매개변수

[cols="5*"]
|===
| 이름 | 유형 | 에서 | 필수 요소입니다 | 설명 


| account_id | 문자열 | 경로 | 참  a| 
포함하는 계정 리소스의 ID

* 예: {{.Account}}




| group_id | 문자열 | 경로 | 참  a| 
포함하는 그룹 리소스의 ID



| user_id | 문자열 | 경로 | 참  a| 
포함하는 사용자 리소스의 ID



| unreadNotification_id | 문자열 | 경로 | 참  a| 
목록에 표시할 unreadNotification 컬렉션의 ID

|===
