= Astra API(ACC) LDAP 사용자 엔드포인트
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
구성된 LDAP(Lightweight Directory Access Protocol) 서버의 사용자를 확인하십시오. 이러한 엔드포인트는 읽기 전용입니다.

LDAP 사용자 API는 구성된 LDAP 서버 내의 LDAP 사용자에 대한 읽기 전용 액세스를 제공합니다.
