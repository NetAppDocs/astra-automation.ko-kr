= 자격 증명 삭제
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
자격 증명 리소스를 삭제하여 지정된 자격 증명과 연결된 액세스 권한을 제거합니다. 이 기능은 액세스 권한을 취소하거나 시스템에서 만료된 자격 증명을 제거해야 할 때 유용합니다.



[[http-method-and-endpoint]]
== HTTP 메서드 및 끝점입니다

[.api-doc-operation .api-doc-operation-delete]#삭제# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/credentials/{credential_id}`#



[[usage-notes]]
== 사용 참고 사항

지정된 Credential API 리소스를 제거합니다.

*부작용*

* 삭제하려는 자격 증명이 다른 리소스나 API에서 사용되는 경우, 삭제로 인해 다른 API 또는 시스템 전체에 의도하지 않은 부작용이 발생할 수 있습니다.
