= Astra API(ACC) 버킷 엔드포인트
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Astra Control에서 애플리케이션 백업을 저장하는 데 사용하는 버킷을 관리합니다.

Bucket API는 Astra에서 애플리케이션 백업을 저장하는 데 사용되는 버킷에 대한 액세스를 제공합니다.
