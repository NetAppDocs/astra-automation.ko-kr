= Astra API(ACC) 실행 후크 엔드포인트
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
애플리케이션의 실행 후크를 생성하고 관리하십시오. 각 후크는 추가 구성을 포함하며 후크 소스를 참조합니다.

실행 후크 API를 사용하면 실행 후크를 간단하게 관리할 수 있습니다. 실행 후크에는 추가 구성과 후크 소스 리소스에 대한 참조가 포함됩니다.
