= 새 패키지 생성
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/packages`#

생성할 Package API 리소스에 대해 원하는 값을 나타냅니다.



== 매개변수

[cols="5*"]
|===
| 이름 | 유형 | 에서 | 필수 요소입니다 | 설명 


| account_id | 문자열 | 경로 | 참  a| 
포함하는 계정 리소스의 ID

* 예: {{.Account}}


|===


== 요청 본문

생성할 Package API 리소스에 대해 원하는 값을 나타냅니다.

[cols="4*"]
|===
| 이름 | 유형 | 필수 요소입니다 | 설명 


| 유형 | 문자열 | 참  a| 
리소스의 미디어 유형입니다. 정의된 값은 다음과 같습니다.

* "application/astra-package"




| 버전 | 문자열 | 참  a| 
리소스 버전입니다. 정의된 값은 다음과 같습니다.

* "1.0"




| packageName | 문자열 | 참  a| 
패키지 이름이 포함된 JSON 문자열입니다. 정의된 값은 다음과 같습니다.

* 최소 길이: 1
* 최대 길이: 31 예시 값은 다음과 같습니다.
* "acc"
* "acs"
* "Trident"




| packageVersion | 문자열 | 참  a| 
패키지의 SemVer를 포함하는 JSON 문자열입니다. 정의된 값은 다음과 같습니다.

* SemVer 스키마를 준수합니다.




| packageType | 문자열 | 참  a| 
패키지 유형을 나타내는 JSON 문자열로, 전체 설치 패키지인지 패치인지 여부를 나타냅니다. 정의된 값은 다음과 같습니다.

* "설치"
* "패치"




| bundleName | 배열[string] | 거짓  a| 
패키지가 포함된 번들의 이름을 포함하는 JSON 문자열의 JSON 배열입니다.



| severityLevel | 문자열 | 참  a| 
이 패치 또는 설치의 심각도 수준을 설명하는 JSON 문자열입니다. 정의된 값은 다음과 같습니다.

* "recommended" - 설치를 권장합니다 - 기본값
* "critical" - 중요한 버그 수정 및/또는 보안 패치를 해결하기 위해 설치를 강력히 권장합니다




| 이미지 | 배열[link:#images["이미지"]] | 거짓  a| 
패키지의 일부인 Docker 이미지를 각각 포함하는 JSON 객체의 JSON 배열입니다.



| 아티팩트 | 배열[link:#artifacts["아티팩트"]] | 거짓  a| 
이 패키지와 관련된 추가 아티팩트(바이너리 및 기타)를 설명하는 JSON 객체의 JSON 배열입니다.



| 파일 | 배열[link:#files["파일"]] | 거짓  a| 
이 패키지와 관련된 이미지 이외의 아티팩트를 각각 나타내는 JSON 객체의 JSON 배열입니다.



| upgradableVersions | link:#upgradableVersions["upgradableVersions"] | 거짓  a| 
패키지 버전으로 업그레이드할 수 있는 최소 및 최대 버전을 포함하는 JSON 객체입니다.



| 종속성 | 배열[link:#dependencies["종속성"]] | 거짓  a| 
이 패키지를 설치하는 데 필요한 특정 종속성의 최소 버전을 설명하는 JSON 객체의 JSON 배열



| 메타데이터 | link:#type_astra_metadata["type_astra_메타데이터"] | 거짓  a| 
리소스와 연결된 클라이언트 및 서비스 지정 메타데이터입니다. 정의된 값은 다음과 같습니다.

* Astra 메타데이터 스키마를 준수합니다. 생성 시 지정하지 않으면 레이블이 없는 메타데이터 객체가 생성됩니다.

리소스의 전역 고유 식별자입니다. 정의된 값은 다음과 같습니다.

* UUIDv4 스키마를 준수합니다.




| packageName | 문자열 | 참  a| 
패키지 이름이 포함된 JSON 문자열입니다. 정의된 값은 다음과 같습니다.

| packageType | 문자열 | 참  a| 
패키지 유형을 나타내는 JSON 문자열로, 전체 설치 패키지인지 패치인지 여부를 나타냅니다. 정의된 값은 다음과 같습니다.

* "설치"

패키지가 포함된 번들의 이름을 포함하는 JSON 문자열의 JSON 배열입니다.



| severityLevel | 문자열 | 참  a| 
이 패치 또는 설치의 심각도 수준을 설명하는 JSON 문자열입니다. 정의된 값은 다음과 같습니다.

* "recommended" - 설치를 권장합니다 - 기본값
* "critical" - 중요한 버그 수정 및/또는 보안 패치를 해결하기 위해 설치를 강력히 권장합니다




| packageState | 문자열 | 참  a| 
패키지의 작동 상태를 나타내는 값을 포함하는 JSON 문자열입니다. 패키지 검증 및 가져오기가 완료되면 상태는 "complete"로 표시됩니다. 그렇지 않으면 상태는 "incomplete"로 표시됩니다. 정의된 값은 다음과 같습니다.

* "verifying" - 패키지가 유효성 검사를 받고 있습니다.
* "corrupt" - 패키지가 손상되었습니다.
* "incomplete" - 패키지에 일부 요소가 누락되었습니다.
* "available" - 패키지와 관련된 모든 요소가 사용 가능하며 패키지를 바로 사용할 수 있습니다.




| packageStateTransitions | 배열[link:#type_astra_stateTransition["type_astra_stateTransition"]] | 참  a| 
JSON 객체의 JSON 배열로, 각 객체는 지정된 상태에서 허용되는 상태 전환 집합을 나타냅니다. 각 JSON 객체에는 "from" 및 "to" 필드가 포함되어 있으며, "from" 값은 상태 이름이고 "to" 값은 허용되는 대상 상태의 배열입니다. 정의된 값은 다음과 같습니다.

* 상태 전이 스키마를 준수합니다.




| packageStateDetails | 배열[link:#type_astra_stateDetail["type_astra_stateDetail"]] | 참  a| 
현재 "state"에 대한 추가 세부 정보를 나열하는 JSON 객체의 JSON 배열입니다. 사용 가능한 세부 정보가 없으면 이 배열은 비어 있습니다.

* 최소 항목: 0




| 이미지 | 배열[link:#images["이미지"]] | 거짓  a| 
패키지의 일부인 Docker 이미지를 각각 포함하는 JSON 객체의 JSON 배열입니다.



| 아티팩트 | 배열[link:#artifacts["아티팩트"]] | 거짓  a| 
이 패키지와 관련된 추가 아티팩트(바이너리 및 기타)를 설명하는 JSON 객체의 JSON 배열입니다.

이 패키지와 관련된 이미지 이외의 아티팩트를 각각 나타내는 JSON 객체의 JSON 배열입니다.



| upgradableVersions | link:#upgradableVersions["upgradableVersions"] | 거짓  a| 
패키지 버전으로 업그레이드할 수 있는 최소 및 최대 버전을 포함하는 JSON 객체입니다.



| 종속성 | 배열[link:#dependencies["종속성"]] | 거짓  a|

| 메타데이터 | link:#type_astra_metadata["type_astra_메타데이터"] | 참  a| 
리소스와 연결된 클라이언트 및 서비스 지정 메타데이터입니다. 정의된 값은 다음과 같습니다.
