= 그룹 삭제
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
지정된 그룹 리소스를 삭제합니다. 이 기능을 사용하여 시스템에서 그룹과 해당 그룹에 연결된 역할 바인딩을 함께 제거할 수 있습니다.



[[http-method-and-endpoint]]
== HTTP 메서드 및 끝점입니다

[.api-doc-operation .api-doc-operation-delete]#삭제# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/groups/{group_id}`#



[[usage-notes]]
== 사용 참고 사항

지정된 그룹 API 리소스를 제거합니다.

*부작용*

* 그룹과 관련된 다음 리소스가 삭제됩니다.
* 그룹을 참조하는 역할 바인딩




[[parameters]]
== 매개변수

[cols="5*"]
|===
| 이름 | 유형 | 에서 | 필수 요소입니다 | 설명 


| account_id | 문자열 | 경로 | 참  a| 
포함하는 계정 리소스의 ID

* 예: {{.Account}}




| group_id | 문자열 | 경로 | 참  a| 
목록에 표시할 그룹 컬렉션의 ID

|===
