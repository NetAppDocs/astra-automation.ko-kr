= Astra API(ACC) 클라우드 엔드포인트
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
클라우드 리소스를 관리하여 특정 클라우드에 연결하고 해당 클라우드 내의 클러스터 및 애플리케이션을 관리할 수 있습니다.

클라우드 API는 클라이언트가 특정 클라우드에 연결하여 클러스터 노드 및 애플리케이션을 관리할 수 있도록 클라우드 리소스에 대한 액세스를 제공합니다.
