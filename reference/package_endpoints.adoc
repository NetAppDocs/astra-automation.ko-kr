= Astra API(ACC) 패키지 엔드포인트
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Astra Control에 등록된 설치 가능한 소프트웨어 패키지를 관리하세요. 등록한 패키지에 따라 사용 가능한 업그레이드가 결정됩니다.

패키지 API는 설치 가능한 소프트웨어 패키지를 나타냅니다.
