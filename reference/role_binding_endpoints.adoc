= Astra API(ACC) 역할 바인딩 엔드포인트
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
계정 내 사용자 또는 그룹에 권한을 부여하는 역할 바인딩을 관리합니다. 역할 바인딩은 사용자 또는 그룹을 역할에 연결합니다.

역할 바인딩 API는 사용자-계정 쌍 또는 그룹-계정 쌍 간의 관계와 이러한 쌍에 부여된 권한 집합(역할)을 설명합니다.
