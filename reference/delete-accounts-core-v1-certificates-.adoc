= 인증서 삭제
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
인증서를 삭제합니다. 더 이상 필요하지 않은 특정 Certificate API 리소스를 제거하려면 이 엔드포인트를 사용하십시오.



[[http-method-and-endpoint]]
== HTTP 메서드 및 끝점입니다

[.api-doc-operation .api-doc-operation-delete]#삭제# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/certificates/{certificate_id}`#



[[usage-notes]]
== 사용 참고 사항

지정된 Certificate API 리소스를 제거합니다.



[[parameters]]
== 매개변수

[cols="5*"]
|===
| 이름 | 유형 | 에서 | 필수 요소입니다 | 설명 


| account_id | 문자열 | 경로 | 참  a| 
포함하는 계정 리소스의 ID

* 예: {{.Account}}




| certificate_id | 문자열 | 경로 | 참  a| 
목록에 표시할 인증서 모음의 ID

|===


[[response]]
== 응답

[source]
----
Status: 204, Indicates if the certificate resource was deleted.
----
