= Astra API(ACC) 애플리케이션 자산 엔드포인트
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Astra Control이 애플리케이션 관리에 사용하는 내부 상태 정보 모음에 액세스하십시오.

애플리케이션 자산 API는 애플리케이션 관리에 사용되는 상태 정보의 내부 컬렉션에 대한 액세스를 제공합니다.
