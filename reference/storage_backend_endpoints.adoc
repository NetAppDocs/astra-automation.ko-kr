= Astra API(ACC) 스토리지 백엔드 엔드포인트
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
관리형 클러스터와 애플리케이션이 사용할 수 있는 스토리지 서비스를 제공하는 스토리지 백엔드를 관리합니다.

Storage Backend API는 관리형 클러스터 및 애플리케이션에서 사용할 수 있는 스토리지 서비스 제공업체(스토리지 백엔드)의 표현에 대한 액세스를 제공합니다.
